# TCC ProjectHub — Render + Supabase

## Deploy
1. Push this folder to GitHub.
2. In Render create a **Web Service** from the GitHub repository.
3. Build command: `npm install`
4. Start command: `npm start`
5. Add `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` in Render Environment Variables.
6. `APP_SESSION_SECRET` can be generated by Render or set to a long random value.
7. In Supabase SQL Editor run `supabase/setup.sql` once.

## Security
- Supabase service-role key is server-only.
- Browser talks to the Render API, never directly to database tables.
- Passwords are hashed with Node scrypt.
- Login is rate limited.
- Sessions use signed, expiring bearer tokens.
- Admin actions are checked server-side.
- Chat and saved code are checked server-side.
- HTML preview is sandboxed by the browser iframe.
- No secrets belong in GitHub.

## GitHub workflow
Edit -> commit -> push -> Render automatically redeploys.
